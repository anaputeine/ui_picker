# ui_picker business requirements

## Description

Many mistakenly see UI/UX design as a simple "pick pretty fonts and colors" activity, while it is actually a lot more than that. Good UI/UX is about how people actually use a product: button states need to be clearly distinguishable, text and background colors need to be readable, and the main actions of a UI page need to be easily noticeable and stand out from the rest of the page.

In the current era of AI-generated products, the UI is one of the components that cannot be done well without a professional to look it over. Developers often do not pay attention to the usability of their product, which leads to confusing websites and apps with yellow text on orange backgrounds, unreadable content, poor accessibility and no clear navigation. With a bad user-facing design, the product is immediately bad, no matter how good its actual functionality is.

This project aims to help with that problem. It will be useful for designers who are looking for guidance when they start designing applications, as well as for developers who build with AI tools.

## Product

The UI picker is a website that will randomly generate a design system for a website or an application from curated options that follow good UI/UX practices: readability, clarity and accessibility. It will include:

- styled font options for various UI segments, like title, subtitle, body and more
- a styled icon set that can be used for buttons and symbols
- a color palette divided into sections for text, icons, backgrounds and button states

The website will also demonstrate an interactive UI example built out of the suggested design system components, so that users can try it out and see whether they truly like the UI.

All styles will be available to copy as CSS right away.
